Added a full band AM/FM station scan with a saved, sorted Memory list of up to 256 stations per band and live scan results in the left panel. The Memory menu has Add Current, Clear Scan, Append Scan, and Clear entries; use Add Current to save the tuned frequency and see a persistent result message, or hold Clear Scan or Append Scan twice to confirm a scan. Cancelling a scan restores the previous Memory list, while a successful add or scan closes the menu. Memory result and error messages remain visible long enough to read. Hold a saved frequency or Clear twice to confirm deletion. Previously saved 128-station lists need to be rescanned. Regular encoder tuning now defaults to Memory; choose Memory or Step in the main menu's TuneMode submenu. The original 99-slot Memory menu is now named Favorite.
