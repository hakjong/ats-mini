Added a full band AM/FM station scan with saved, sorted Memory lists shared by all FM, MW, or SW bands and live scan results in the left panel. Each list holds up to 256 stations, while browsing, clearing, and ATS operate only within the current band; ATS preserves frequencies saved for other bands in the same list. A red M above the frequency unit indicates that the current frequency is saved. The Memory menu has Add Current, ATS, and Clear entries; opening it on a saved frequency selects that entry automatically. Use Add Current to save the tuned frequency and see a persistent result message, or hold ATS twice to confirm replacing the current band's frequencies with scan results. Cancelling a scan restores the previous Memory list, while a successful add or scan closes the menu. Memory result and error messages remain visible long enough to read. Hold a saved frequency or Clear twice to confirm deletion. Previously saved per-band lists need to be rescanned. Regular encoder tuning now defaults to Memory; choose Memory or Step in the main menu's TuneMode submenu. The original 99-slot Memory menu is now named Favorite. The Web UI also uses the Favorite name, shows the shared Memory lists separately, and can download or restore both sets together as a YAML backup.
